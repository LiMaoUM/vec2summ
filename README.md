# Vec2Summ

Code and artifacts for the paper "Summarizing Without the Documents: Probe Placement, Inversion, and Privacy in Embedding-Sketch Summarization" (EACL 2027, Main Conference), by Mao Li and Johann Gagnon-Bartsch.

The release will contain:

- the code and experiment harness;
- per-cell artifacts, including per-seed scores and per-claim audit verdicts, and the aggregate tables;
- for the Twitter corpora: tweet IDs, the fitted sketches after the nearest-document threshold, and the per-component inverted snippets that passed the leakage audit. Document-level embeddings of these corpora are not released, because individual text embeddings are invertible.

The remaining corpora are publicly available from the sources cited in the paper.

The files are being prepared for release.
