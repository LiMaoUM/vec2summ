# Vec2Summ

Code and aggregate results for the paper "Summarizing Without the Documents: Probe Placement, Inversion, and Privacy in Embedding-Sketch Summarization" (EACL 2027, Main Conference), by Mao Li and Johann Gagnon-Bartsch.

Vec2Summ embeds a corpus, fits a k-component Gaussian mixture over the embeddings, inverts each component mean back into text with Vec2Text, and has a language model summarize the k snippets. The paper studies where such a sketch should be probed, what inversion costs against keeping real documents, and what the sketch leaks about individual documents.

## Contents

- `experiments/`: the experiment scripts. `common.py` holds corpus loading, cached embedding and model calls, the mean-max similarity metric and the judge prompts. `e1_run.py` runs the selection baselines and the Gaussian probe scheme, `e9_gmm.py` the component-mean and spectral probes, `e3_gtr.py` the GTR encoder, `e7_hierarchical.py` the hierarchical baseline, `eval_geval.py` the per-criterion judging, `e8_factuality.py` the claim-level audit, `scaling_curve.py` and `scaling_stream.py` the scaling, single-pass and shard-merge results, and the `analysis_*.py` scripts the statistics and the leakage threshold.
- `experiments/results/tables/`: the aggregate tables and statistics behind every table and figure in the paper.
- `experiments/human_eval/`: the expert-panel protocol, the three annotators' recorded judgments and the scoring script's key.
- `data/tweet_ids/`: tweet IDs of the three Twitter corpora (`*_all.txt`) and of each seeded sample of 1,000 documents, in sample order, one ID per line.
- `data/sketches/`: the fitted sketches of the 21 dataset and seed cells after the nearest-document threshold (cosine 0.959): component weights, means and diagonal covariances of the components that remain. `manifest.json` gives the number of components released per cell.
- `data/snippets/audited_snippets.jsonl`: the inverted snippet of each released component with its support, nearest-document cosine and snippet-to-document token overlap. Handles generated by the inverter are removed.
- `data/per_cell/`: per-cell probe coverage, cross-judge scores, ranks and per-claim audit verdicts, as numbers and labels.
- `experiments/build_release.py`: the script that built `data/` from the cached embeddings and result files.
- `figures/`: the scripts that draw the scaling and leakage figures from the tables.
- `requirements.txt`: package versions used for the reported results.

## Data

The source documents are not redistributed here. AskDocs, Reddit-TIFU and the Amazon reviews are available from the sources cited in the paper. Set `VEC2SUMM_DATA` to the folder that holds them; `experiments/common.py` lists the expected file names and text columns. The scripts call the OpenAI API (`OPENAI_API_KEY`) for `text-embedding-ada-002` and GPT-4.1, and an OpenAI-compatible local server for Llama-3.3-70B-Instruct.

The Twitter corpora are released as tweet IDs. This repository contains no source documents, no document-level embeddings, no user identifiers and no per-cell files that quote source text. Individual text embeddings are invertible, so document-level embeddings of the Twitter corpora are not released.
